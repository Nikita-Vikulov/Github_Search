# GitHub Search App

An Android application for searching GitHub users and repositories with dynamic pagination.

**Tech Stack:** Kotlin, MVVM & Repository Pattern, Coroutines & Flow, Jetpack (ViewModel, Navigation, ViewBinding, Paging 3), Retrofit 2, OkHttp, Glide, REST API.

## Key Features
* Real-time search for GitHub users and repositories
* Detailed user profiles with followers and repository lists
* Pagination via Paging 3 and reactive UI state handling
